## Язык ассемблера

Одна команда в строке: `МНЕМОНИКА операнд, операнд, ...`, комментарий
начинается с `;`. Операнды — неотрицательные целые числа (`127` или
`0x7F`), порядок операндов совпадает с порядком полей B, C, D в
спецификации.

| Команда | Код (A) | Операнды | Действие |
|---------|---------|----------|----------|
| `LOAD B, C` | 85 | B — адрес (14 бит), C — константа (20 бит) | `mem[B] = C` |
| `READ B, C, D` | 245 | B — смещение (15 бит), C, D — адреса (14 бит) | `mem[D] = mem[mem[C] + B]` |
| `WRITE B, C` | 31 | B, C — адреса (14 бит) | `mem[C] = mem[B]` |
| `SQRT B, C` | 118 | B, C — адреса (14 бит) | `mem[mem[C]] = sqrt(mem[B])` |

Пример — тесты из спецификации (`examples/spec_tests.asm`):

```
LOAD  127, 814
READ  252, 300, 303
WRITE 237, 401
SQRT  808, 463
```

## Этап 1. Промежуточное представление

`./run.sh asm ИСХОДНИК РЕЗУЛЬТАТ --test` переводит программу в список
команд и в режиме тестирования выводит поля: `make spec`. Тесты:
`make test`, ошибки: `make errors`.

## Этап 2. Машинный код

Команда кодируется в 7 байт: поля упаковываются по своим битам (A — биты
0–7), байты записываются от младшего к старшему. Ассемблер записывает
двоичный файл, выводит число команд, в режиме тестирования — байты каждой
команды. `make spec` показывает совпадение с тестами спецификации.
